04 / FAQ

Common
questions.

Need help?
Ask on GitHub

Does it really work offline?

Yes, research works offline after setup. Install a model and any collections you want first. Downloads and catalog refresh need an internet connection; research uses the files already on your phone.

Do I need a knowledge collection?

No. A model is required, but collections are optional. The model can answer general questions without a collection, but those answers aren’t checked against saved sources. If you ask it to use only sources and it can’t find enough information, it will say so.

How much should I trust an answer?

Treat it as a starting point, not a guarantee. Models can make mistakes, and a citation does not prove a claim. Read the linked passage and check its context and date. The current collections do not cover every subject.

What stays on my phone?

Research questions, local search, and answer generation stay on the device. There’s no account to create. User-requested downloads contact the model or collection host; this website’s downloads are served by GitHub.

Will it work on my Android phone?

The app requires Android 13 or newer and an arm64 processor. Performance and available storage matter when running a local model. It has been tested on an Infinix X6840; performance on other devices may differ. Allow additional space for model and collection files.

How do I install or update it?

Open the downloaded APK and follow Android’s installation prompts. Public releases use the same project signing key. A locally test-signed build cannot be updated with the public APK; preserve your data before considering a reinstall. See the installation notes.
